## Milestone 3 – Supplier Performance & Transportation Analytics

### Project Overview
This project was developed using Microsoft Power BI as part of the Infosys Springboard Internship. It focuses on analyzing supplier performance and transportation operations using interactive dashboards and DAX measures to support better business decisions.

# Tools Used

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query

# Dashboard 1: Supplier Performance Dashboard

## Objective
To evaluate supplier performance based on quality, reliability, lead time, and order fulfillment.

## Supplier Scorecard Calculation Methodology

The supplier scorecard is calculated using the following KPIs:

- Total Suppliers
- Average Quality Score
- Average Reliability (%)
- Average Lead Time (Days)
- Orders Fulfilled (Proxy)

A Supplier Composite Score is calculated using:

- Quality Score – 40%
- Reliability – 40%
- Lead Time – 20%

Suppliers are classified into:
- High Reliability
- Medium Reliability
- Low Reliability

# Dashboard 2: Transportation Analytics Dashboard

## Objective

To analyze transportation performance, shipping efficiency, and logistics costs.

## Transportation Cost Analysis Methodology

The dashboard analyzes transportation using the following KPIs:

- Average Profit per Order
- Total Discount Given
- Average Discount Rate
- Same-Day Delivery Share
- Late Delivery Rate

These KPIs help evaluate transportation efficiency and logistics performance.

A Heat Map is used to analyze late delivery performance across different markets and regions.


# Key Insights

### Supplier Dashboard

- Identified high-performing suppliers.
- Compared suppliers based on quality, reliability, and lead time.
- Ranked suppliers using Composite Score.
- Classified suppliers into reliability tiers.

### Transportation Dashboard

- Compared shipping modes based on profit and discounts.
- Measured late delivery percentage.
- Identified markets with higher delivery delays.
- Analyzed transportation performance using interactive visuals.

# Business Recommendations

### Supplier Performance

- Continue working with high-performing suppliers.
- Improve quality and reliability of low-performing suppliers.
- Reduce supplier lead time through regular monitoring.

### Transportation Analytics

- Optimize shipping modes with better performance.
- Reduce transportation costs by improving logistics planning.
- Monitor late deliveries regularly.
- Improve delivery efficiency in high-delay regions.


# Conclusion

This project provides interactive dashboards for monitoring supplier performance and transportation efficiency. It enables better supplier evaluation, transportation analysis, and data-driven decision-making through Power BI.
